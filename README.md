# قادر: ربط الصفحة بـ Claude

الصفحة (`public/index.html`) ترسل طلب الطالب أو المعلم إلى الخادم (`server.js`)، والخادم يرسله إلى Claude ويعيد الرد إلى الصفحة وهو يُكتب تدريجياً.

```
الطالب أو المعلم  ->  الصفحة  ->  خادمك (يحمل المفتاح)  ->  Claude
                              <-  الرد يظهر مباشرة   <-
```

## ما تحتاجه

1. **Node.js 18 أو أحدث** على جهازك أو على الاستضافة.
2. **مفتاح واجهة Claude** من console.anthropic.com. هذا حساب منفصل عن تطبيق Claude، وله فوترة حسب الاستخدام. حدّد سقفاً للإنفاق الشهري من إعدادات الحساب هناك.

## التشغيل على جهازك

```
cp .env.example .env      # ثم افتح .env وضع المفتاح
node server.js
```

افتح http://localhost:3000 وجرّب.

## النشر على الإنترنت

أي استضافة تدعم Node تصلح (مثل Render أو Railway أو Fly.io):

- ارفع المجلد كما هو.
- أمر التشغيل: `node server.js`
- أضف المتغيرات في إعدادات الاستضافة: `ANTHROPIC_API_KEY` وهو الأهم، واختيارياً `ACCESS_CODE` و`CLAUDE_MODEL`.
- لا ترفع ملف `.env` إلى GitHub أو أي مكان عام.

## حماية التكلفة والخصوصية

- **المفتاح** يبقى في الخادم فقط، ولا يراه أي زائر.
- **رمز الدخول:** إن ضبطت `ACCESS_CODE` فسيُطلب من كل مستخدم مرة واحدة. استخدمه إن أردت أن تقتصر الأداة على مدرستك.
- **حد الاستخدام:** 30 طلباً لكل جهاز كل 10 دقائق (يمكن تعديله في أعلى `server.js` ضمن `RATE_LIMIT`). يُحفظ العداد في الذاكرة فيُصفَّر عند إعادة تشغيل الخادم.
- **تعليمات قادر** (الشخصية وقواعد كل مهمة) محفوظة في `server.js`، فلا يستطيع الزائر تغييرها أو استخدام الخادم كواجهة عامة.
- **بيانات الطلبة:** الخادم لا يخزّن المحادثات، لكن النص يُرسل إلى Claude للمعالجة. راجع سياسة مدرستك قبل أن يكتب الطلبة معلومات شخصية.

## الملفات

| الملف | الوظيفة |
|---|---|
| `server.js` | الخادم: يقدّم الصفحة ويتصل بـ Claude ويبث الرد |
| `public/index.html` | الصفحة: الشخصية والأزرار والمحادثة |
| `.env.example` | نموذج الإعدادات |
| `package.json` | أمر التشغيل ومتطلب النسخة |
